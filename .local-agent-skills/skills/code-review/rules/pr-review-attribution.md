# PR Review Attribution

When Codex creates or materially updates a pull request, the PR description must
include a short attribution line:

```text
Created by Codex.
```

When Codex posts a pull request review or review summary, include a short
attribution line:

```text
Reviewed by Codex.
```

Do not add this attribution to commits, changelog entries, package metadata, or
user-facing runtime output unless the user explicitly asks for it there.
